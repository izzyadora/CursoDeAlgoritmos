# Curso de Algoritmos
## Curso em vídeo - Prof. Gustavo Guanabara

Olá mundo!
Este repositório reúne os exercícios desenvolvidos durante o estudo de lógica de programação utilizando VisuAlg, uma ferramenta baseada em Portugol que facilita a compreensão dos fundamentos de algoritmos.
O objetivo principal é registrar minha evolução no entendimento de conceitos como:
- Estruturas de decisão
- Estruturas de repetição
- Variáveis e tipos
- Operações matemáticas e lógicas
- Vetores e Matrizes
- Resolução sistemática de problemas
Embora o VisuAlg não seja usado profissionalmente, ele é excelente para reforçar o raciocínio lógico antes de avançar para linguagens como Python, C++, Java etc.

# 📁 Estrutura do Repositório
Cada pasta contém um conjunto de exercícios do curso.
Os arquivos .alg podem ser abertos diretamente no VisuAlg.

# ▶️ Como executar
Instale o VisuAlg: sourceforge.net/projects/visualg30/
Abra o arquivo `.alg` desejado.
Execute para visualizar o funcionamento do algoritmo.

# 🎯 Objetivo
Servir como registro de aprendizado e base inicial para estudos posteriores em estruturas de dados, programação imperativa e boas práticas de desenvolvimento.
